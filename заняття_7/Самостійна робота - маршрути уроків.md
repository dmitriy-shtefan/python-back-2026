# Самостійна робота. Сторінки уроків

## 1. Проста сторінка

Додайте адресу `/contacts/`. Відповідь: `Контакти навчальної платформи`, статус 200.

Створіть функцію у `views.py` вашого застосунку та додайте маршрут у його наявний список `urlpatterns`.

## 2. Урок за числовим ID

Використайте дані у `views.py` поза функціями:

```python
LESSONS = {1: "HTTP", 2: "Routing", 3: "Views"}
```

Додайте маршрут `/lessons/<int:lesson_id>/` і view із відповідним аргументом. Для наявного номера поверніть номер та назву уроку. Для невідомого числового номера поверніть текст `Урок не знайдено` зі статусом 404.

| Адреса | Статус | Очікуваний результат |
| --- | --- | --- |
| `/contacts/` | 200 | `Контакти навчальної платформи` |
| `/lessons/2/` | 200 | `Урок 2: Routing` |
| `/lessons/99/` | 404 | `Урок не знайдено` |
| `/lessons/abc/` | 404 | Маршрут із числовим конвертером не збігається |
| `/` | 200 | Ваша наявна головна сторінка працює |


## 3. Параметр query string

Додайте адресу `/lessons/`. У view прочитайте необов'язковий параметр `topic` через `request.GET`. Якщо ключа немає, використайте `all`. Поверніть отримане значення звичайним текстом. Використайте `content_type="text/plain; charset=utf-8"`.

| Адреса | Статус | Очікуваний результат |
| --- | --- | --- |
| `/lessons/?topic=django` | 200 | `Тема: django` |
| `/lessons/?topic=python` | 200 | `Тема: python` |
| `/lessons/` | 200 | `Тема: all` |

У `path` має бути тільки шлях без `?topic=`. Реальний пошук по словнику не потрібний, завдання перевіряє читання параметра. Усі три нові view становлять повний запланований результат.


Нові шаблони, моделі, міграції та додаткові пакети для цієї роботи не потрібні. Після таймера відбудеться окремий розбір і перевірка результатів кожного присутнього.
