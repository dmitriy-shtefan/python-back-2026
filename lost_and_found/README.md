# Бюро знахідок

Стартовий Django-проєкт до заняття 9. Сайт показує, які речі знайшли в навчальному закладі та де їх можна забрати.
Спільні стилі записані в кожному HTML-шаблоні, а код пошуку міститься в шаблоні списку знахідок.

## Як запустити

У папці `lost_and_found` відкрийте термінал з активним віртуальним середовищем і виконайте:

```sh
python -m pip install -r requirements.txt
python manage.py runserver
```

Відкрийте [головну сторінку](http://127.0.0.1:8000/), а потім перейдіть через меню до списку знахідок і сторінки видачі. Приклади знахідок зберігаються в `bureau/views.py`.
