# Практичне завдання 1. Запити через Django ORM

Ігровий клуб веде каталог настільних ігор. Адміністратор хоче швидко знаходити ігри, доступні для видачі, і бачити видавця кожної гри.

Відкрийте готовий проєкт `board_game_club`. У застосунку `catalog` уже є модель `BoardGame` з полями `title`, `max_players` та `is_available`. У базі `db.sqlite3` є 50 ігор та обліковий запис адміністратора.

Запустіть `python manage.py shell` та імпортуйте `BoardGame` з `catalog.models`.

1. Використайте `BoardGame.objects.all()`, щоб отримати всі ігри й вивести їхні назви.
2. Використайте `BoardGame.objects.filter()`, щоб отримати доступні ігри й вивести їхні назви.
3. Знайдіть доступні ігри, у які можуть зіграти щонайменше п'ятеро людей. Для порівняння кількості гравців скористайтеся суфіксом `__gte`.
4. Через `.count()` підрахуйте всі ігри та ігри, які відповідають обом умовам із кроку 3.

Для перевірки на початкових даних. У каталозі 50 ігор, 38 із них доступні, а 16 доступних ігор підходять для групи з п'яти людей.
