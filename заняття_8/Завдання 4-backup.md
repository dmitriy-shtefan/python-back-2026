# Завдання 4

Використовуючи механізм шаблонів, створіть вебдодаток для кулінарних рецептів. Назва рецепту передається через рядок пошуку.

Наприклад:

- `127.0.0.1:8000/?recipe=goulash` - потрібно відобразити рецепт гуляшу;
- `127.0.0.1:8000/?recipe=dumplings` - потрібно відобразити рецепт вареників.
